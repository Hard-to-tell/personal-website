贤者时间突发奇想，能不能跟ai聊xp，让它更懂我？于是有了这个项目：站内推荐只有热门榜，自己搜又总翻到同一批。所以写了 [本命 HONMEI](https://github.com/Hard-to-tell/honmei-radar)：读懂你在**哔咔**和**禁漫**的收藏，去禁漫里挑你还没看过、大概率会喜欢的作品。



## 它能做什么

- **开卷**：一次推荐十来本，叫一卷（Vol.1、Vol.2……），每本都写着“为何是它”。
- **表态**：每本可以点 心动 / 略过 / 不喜欢 / 读过，点得越多越准。
- **调音**：一轮给 5 本打分（本命 / 喜欢 / 一般 / 不太喜欢），帮它分清哪些是真爱。
- **本命报告**：把收藏整理成几类口味、常追的作者、口味怎么变的。

两条原则：**数据只存在自己电脑上**；**推荐不靠大模型**，全是本地统计，快、免费、说得清理由。

## 推荐流程

![推荐流程：收藏 → ① 读懂口味 → ② 找候选 → ③ 打分 → ④ 排成一卷 → 推荐；⑤ 你的反馈回头修正口味](/images/honmei/flow.svg)

## ① 读懂口味

每本漫画对程序来说就是一串**标签**，加上**作者**和**原作**。

- **偏爱的标签**：看的不是出现多少次，而是**比一般作品多出多少**。站里 30% 是全彩、你收藏里 60% 是全彩，就是偏爱 2 倍。到处都有的标签不会被误当成你的爱好。
- **口味簇**：用 k-means 把收藏按标签分成 3～6 摞，每摞是一种口味，避免算出一个谁都不像的“平均口味”。
- **熟悉的作者**：在收藏里出现越多越亲，但有上限，免得一个高产作者占满整卷。

（“一般作品”是从榜单、最新、随机分类里抽的约 300 本。）

## ② 找候选

去禁漫里分几路搜：**熟悉作者**的新作、**每个口味簇**的代表标签、常看**原作**的其他同人、最近收藏的**相关作品**，再加几本**热门**。已收藏、表过态、推荐过的，以及同一本的其他版本，全部去掉。

## ③ 打分


| 分项 | 意思 |
| ------ | ----------------- |
| 标签匹配 | 和你最像的几本收藏重合多少标签 |
| 口味契合 | 它的标签加起来是不是你偏爱的那一挂 |
| 作者 | 是不是熟悉的作者 |
| 标题 | 是不是续作、系列作 |
| 踩雷（扣分） | 像不像你略过、不喜欢过的作品 |
| 热度 | 只占很小比重 |


按权重加起来就是总分，作者和标签权重最高。

一个踩过的坑：哔咔平均每本 12 个标签，禁漫只有 6 个多，直接比较的话哔咔收藏几乎没用。解决办法是比较时**只轻罚“收藏有、候选没有”的标签**，并自动学两站标签的对照（同一本两站都收藏了，就能看出哪些标签是一个意思）。

## ④ 排成一卷

直接取前十名，常常整卷都是同一种口味、甚至同一个作者。所以：

- **每个口味簇都有名额**，按占比开平方分。占比 70% / 20% / 10% 的三摞，名额约 52% / 28% / 20%，小众口味也有位置。
- **同一作者、同一原作限量。**
- **留一本热门**换换口味，再留几个位置**试探**还拿不准的口味。

## ⑤ 越用越懂你


| 你做的事 | 它怎么用 |
| ------- | --------------------------- |
| 心动 / 略过 | 标签加减分；各满 3 条后微调③的权重，调坏了自动退回 |
| 调音打分 | 本命算 2 倍，不太喜欢的不算；某种口味两次被嫌就少推 |
| 继续收藏 | 新收藏权重更高；报告里能看出口味往哪边挪了 |


## 效果

把最近 20% 的收藏藏起来，看推荐能不能把它们找回来。在我自己的收藏上：


|  | 旧版 v0.2 | 新版 v0.3 |
| -------- | ------- | ------- |
| 每 20 本猜中 | 3 本 | 6 本多 |
| 理由来自哔咔收藏 | 5% | 58% |


不过没收藏不等于不喜欢，这个数字更适合比较版本，不算准确率。

## 最后

下一步想让它看懂**画风**，目前标签相同、画风天差地别的作品它还分不出来。

做下来最大的感受：推荐里难的不是模型多复杂，而是想清楚几个朴素的问题，比如常见标签该不该打折、两站标签不对等怎么办、大口味会不会吃掉小口味。
