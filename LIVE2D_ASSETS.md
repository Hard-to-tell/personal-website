# Live2D assets

- Asuna runtime files: `weblive2d` 1.0.12, using the `asuna_01`,
  `asuna_02`, `asuna_03`, and `asuna_04` outfits. Shared face, hair,
  expression, motion, and physics files are stored only once.
- Hiyori Momose: Live2D official sample data, `hiyori_free` runtime files only.
- Renderer: PixiJS 6.5.10 and `pixi-live2d-display` 0.4.0.
- Cubism 2 runtime: bundled from `weblive2d` 1.0.12.
- Cubism 4 Core: downloaded from the official Live2D Web SDK endpoint.

The Hiyori sample remains subject to Live2D's Free Material License Agreement and
the model-specific sample data terms. The renderer license files are under
`vendor/licenses/`.
